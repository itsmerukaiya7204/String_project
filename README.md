#String Analyzer Project in C

This project is developed in c language to perform different operations on a string entered by the users.

##Features
1.Find Length of String-using strlen()
2.Reverse the string
3.check palindrome-check if the string is same from both sides
4.count vowels and consonants
5.frequency of string 

##How to Run
1.compile the code:
'gcc string_project.c'
2.Run the program:
'.\a.exe'

##Tools Used
-Language:C Language
-Compiler:GCC
-Editor:VS Code
